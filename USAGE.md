# Teleport Audio Downloader Usage

## Install

1. Open the latest release.
2. Download `TeleportAudioDownloader_Setup_<version>.exe`.
3. Run the installer.
4. Launch Teleport Audio Downloader from the Start Menu or desktop shortcut.

## Search Downloads

1. Open the Search tab.
2. Enter an artist, song title, or keyword.
3. Click Search.
4. Add the results you want to the queue.
5. Click Download.

## Direct URL Downloads

1. Open the Direct URL tab.
2. Paste a YouTube video or playlist URL.
3. Leave Download playlists enabled if you want playlist URLs expanded.
4. Click Download.

The URL field is cleared after the URL is queued so the same playlist is not downloaded again by accident.

## Existing Files

By default, existing files are skipped.

To change this:

1. Open Settings.
2. Change Existing files to Skip or Overwrite.
3. Save settings.

## Audio Formats

Supported output formats:

- MP3
- FLAC
- Opus
- AAC
- WAV

## Output Folder

Files are saved to your Music folder by default. Use Browse in the main window to choose a different output folder.

## Updates

The app can check GitHub Releases for newer installer versions.
