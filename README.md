# Teleport Audio Downloader

Teleport Audio Downloader is a Windows desktop app for downloading YouTube videos as high-quality audio files.

This repository is used for public releases and user documentation. Source code is not published here.

## Download

Download the latest installer from the [Releases](../../releases) page.

The installer includes the application and required media tools. No additional setup is normally required.

## Features

- Search YouTube by artist, title, or keyword.
- Download direct YouTube URLs.
- Download playlists.
- Save audio as MP3, FLAC, Opus, AAC, or WAV.
- Embed metadata and artwork when available.
- Queue multiple downloads.
- Choose whether existing files are skipped or overwritten.
- Supports light and dark themes.

## Checksums

Each release includes a `SHA256SUMS.txt` file. Use it to verify the installer download.
